# 🌦️ Météo Sénégal

Application de météo en temps réel pour les villes du Sénégal, construite avec Angular.

## ✨ Fonctionnalités
- Météo en direct via l'API Open-Meteo (gratuite, sans clé)
- 6 villes : Dakar, Thiès, Saint-Louis, Ziguinchor, Kaolack, Touba
- Recherche d'une ville
- Prévisions à court terme : prochaines heures
- Prévisions à long terme : 7 jours
- Conseils selon la météo (pluie, chaleur, orage...)
- Gestion des erreurs de connexion

## 🚀 Lancer le projet
```bash
npm install
